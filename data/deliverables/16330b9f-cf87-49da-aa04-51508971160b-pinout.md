# M5Stack 智慧花園 — 腳位規劃 (Pinout)

## Target Board: M5Stack Core S3 (ESP32-S3)

| Function | GPIO | Connector | Notes |
|----------|------|-----------|-------|
| Soil Moisture Sensor (ADC) | GPIO 1 | Grove Port A (Red wire) | Analog input, 0–3.3V range |
| VCC (3.3V) | 3.3V | Grove Port A (Black wire) | Sensor power |
| GND | GND | Grove Port A (Black wire) | Common ground |
| Water Pump Relay | GPIO 46 | Header pin | Active HIGH relay module |
| Status LED | GPIO 21 | Internal | Error indication (optional) |

## Soil Moisture Sensor Calibration

| Condition | ADC Reading | Percentage |
|-----------|-------------|------------|
| Sensor in water (wet) | ~900 | 100% |
| Moist soil | ~1100–1300 | 50–70% |
| Dry soil | ~1800 | 20% |
| Sensor in air (dry) | ~2800–3200 | 0% |
| Sensor disconnected | 4095 | Error |

> Note: Calibration varies by sensor model and soil type.
> Adjust `MOISTURE_THRESHOLD` in firmware to match your sensor.

## Watering Logic

1. Read moisture every 5 seconds
2. If moisture < threshold AND cooldown elapsed → water for 5 seconds
3. Wait 60 seconds minimum between watering cycles
4. ~16 ml water per cycle (with typical 200 ml/min pump)

## MQTT Topics

| Topic | Direction | Purpose |
|-------|-----------|---------|
| `garden/smart-garden/telemetry` | Device → Broker | JSON telemetry data |
| `garden/smart-garden/cmd` | Broker → Device | Commands: `water_now`, `status` |

## Build & Flash

```bash
# Install PlatformIO
pip install platformio

# Build
cd smart-garden
pio run

# Flash to M5Stack (USB-C connected)
pio run --target upload

# Monitor serial output
pio device monitor --baud 115200
```
