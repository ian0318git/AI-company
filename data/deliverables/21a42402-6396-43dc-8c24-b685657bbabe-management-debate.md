# 重大專案交付管理策略辯論報告

> **專案**: 重大專案交付管理策略
> **辯論雙方**: Results_Director vs People_Specialist
> **仲裁**: CEO
> **日期**: 2026-07-01

---

## 背景

團隊目前處於重大專案交付關鍵期，出現嚴重過勞跡象且進度有些許落後。針對管理策略進行辯論。

---

## 第一輪：診斷現狀

### Results_Director — 鐵血結果導向

現在是交付關鍵期。客戶合約有違約金條款，延遲一天罰款 15 萬。這不是「要不要衝」的問題，是**公司能不能活過這個月**的問題。

團隊過勞？我同意這很嚴重。但**最大的壓力來源不是工作量，是不確定性**。專案一天不交付，團隊一天睡不好。與其拖著慢慢做痛苦三個月，不如**集中火力兩週衝刺，然後給兩週全薪休假**。

我的數據：過去三次專案延遲，根本原因都不是人力不足 — 是**優先級混亂**和**需求變更**。如果我們現在鐵血鎖定 scope、每天 standup 追進度、週末加班衝刺，我有信心兩週內達標。

### People_Specialist — 彈性關懷導向

Director 的邏輯有一個根本矛盾：**你認為過勞的解法是加班**。

我的數據：目前團隊的每週工時中位數是 62 小時。過去一個月，我們有 3 個人請了病假，2 個人提出了離職意願。如果現在再推「兩週衝刺」，你確定這兩週內不會有第 3 個人提離職？

心理學研究很清楚：**睡眠不足 6 小時、連續工作超過 50 小時後，錯誤率上升 40%**。你所謂的「衝刺」，實際上會產出更多 bug，然後需要更多時間修 — 這叫**死亡螺旋**。

---

## 第二輪：解決方案對決

### Results_Director 方案：兩週衝刺

| 措施 | 預期效果 |
|------|---------|
| 鎖死 scope，凍結需求變更 | 消除不確定性，聚焦交付 |
| 每日同步追蹤進度 | 問題當天發現當天解 |
| 週末加班 + 餐費全補 | 加速產出 |
| 達標後兩周全薪假 | 實質補償過勞 |
| 交付獎金：每人額外一個月薪資 | 激勵到位 |

### People_Specialist 方案：減壓調整

| 措施 | 預期效果 |
|------|---------|
| 與客戶協商延遲兩週，提供階段性交付 | 買時間 |
| 砍掉 20% 非關鍵功能到 v1.1 | 減少工作量 |
| 每人每週強制一天不加班 | 身體恢復 |
| 週三無會議日 + 核心工作時間 10-15 不中斷 | 深度工作保護 |
| 聘請兩位短期約聘分擔測試和文件 | 增加人力 |

### CEO 提問

> 「People_Specialist，如果客戶拒絕延遲呢？Director，你的方案中如果有人在衝刺期間倒下，備案是什麼？」

**People_Specialist**: 即使客戶拒絕全額延遲，我們也可以提出「核心功能準時、非核心功能兩週後補上」的方案。這不是認輸，是**誠實溝通**。多數客戶寧願拿到 80% 功能準時，也不要 100% 功能延遲還充滿 bug。

**Results_Director**: 如果有人倒下，我們有**輪替機制**：不會讓同一個人連續兩天加班超過 4 小時。核心團隊每人負責一個模組，有一個人出狀況，其他模組不受影響繼續前進。這是管理，不是賭博。

---

## 第三輪：交叉質詢

### People_Specialist 質詢 Results_Director

> 「你提到輪替。但你我都知道這個專案的關鍵路徑上有 3 個瓶頸人物 — A 工程師、B 架構師、C 測試主管。這三個人任何一個倒下，輪替根本輪不起來。你的『備案』實際上不存在。」

### Results_Director 質詢 People_Specialist

> 「你說砍 20% 功能。現在已經延遲了，再砍功能客戶的採用意願會下降。你有沒有算過，如果客戶因為功能不完整而拒絕驗收，重新談判要多久？你買的兩週不是兩週，而是開啟了一個新的談判黑洞。」

---

## CEO 最終裁定

聽完雙方完整的論述，我做出以下決定：

### 決策：階段性衝刺 + 保護機制（Hybrid 方案）

兩個方案不是互斥的。**最好的管理不是選邊站，是組合雙方的精華。**

| 維度 | 採用 | 來源 |
|------|------|------|
| 時間線 | 與客戶協商延遲一週 + 階段交付 | People_Specialist |
| Scope | 砍 10% 非關鍵功能（非 20%） | 折衷 |
| 執行 | 兩週集中衝刺，鎖 scope | Results_Director |
| 保護 | 每週強制休一天 + 週三無會議 | People_Specialist |
| 激勵 | 達標後每人一週假 + 半個月獎金 | 折衷 |
| 備援 | 聘一位短期約聘分擔測試 | People_Specialist |
| 追蹤 | 每日 standup | Results_Director |

### 為什麼不選任一邊

- 全盤採納 Director：**高風險賭注**。團隊已經 62 小時/週，再推可能真的有人倒下。倒下一個瓶頸 = 全盤崩潰
- 全盤採納 Specialist：**太慢**。協商 + 砍功能 + 約聘面試，每個環節都有延遲風險。買的時間可能不夠

### 實施時程

| 日期 | 行動 |
|------|------|
| **Day 1** | 客戶溝通：延遲一週 + 階段交付方案 |
| **Day 3** | Scope 凍結（砍 10%），約聘到崗 |
| **Day 5-16** | 兩週衝刺（每週休一天 + 週三無會議） |
| **Day 17** | 內部驗收 + bug fix |
| **Day 18-19** | 緩衝 |
| **Day 20** | 正式交付 |
| **Day 21+** | 團隊休假一週 + 獎金發放 |

### 底線

如果 Day 1 客戶拒絕任何延遲 → 啟動 Director 純衝刺方案，但加入強制輪休（連續加班不超過 3 天）。如果衝刺期間有人員離職 → 立即啟動約聘轉正流程，同時砍更多 scope 保住核心交付。

---

## 核心原則

> **「管理不是選鐵血或關懷。管理是在現實約束下，找到那條能同時保護專案和保護人的窄路。」**

這場辯論的價值不在於誰贏，而在於雙方都提出了對方不願面對的真相。Director 提醒了我們**時間是真的敵人**。Specialist 提醒了我們**人是真的資產**。兩者都對。策略就是在這兩者之間畫一條可行的線。
