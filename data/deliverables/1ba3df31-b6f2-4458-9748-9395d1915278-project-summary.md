## 韌體架構

```
src/
├── main.cpp                    # CoreS3 主程式（IMU 體感 + UART 命令）
├── stackchan/main.cpp          # StackChan 端（UART 接收 + servo/表情）
├── hal/
│   ├── IMUSensor.cpp/h         # BMI270 姿態感測 (Madgwick 濾波)
│   ├── ServoController.cpp/h   # StackChan 伺服控制
│   ├── UartComm.cpp/h          # CoreS3 ↔ StackChan 通訊協議
│   ├── ButtonInput.cpp/h       # 按鈕輸入
│   ├── DisplayCoreS3.h         # CoreS3 TFT 顯示
│   └── DisplaySSD1306.h        # StackChan OLED 顯示
├── IAudio.h / IUartComm.h      # 抽象介面
└── ErrorHandler.cpp/h          # 除錯與錯誤處理
```

## 互動模式

1. **體感遙控** — CoreS3 IMU 偵測姿態 → UART 命令 → StackChan servo 跟隨
2. **表情互動** — StackChan 根據 CoreS3 按鈕/姿態切換 OLED 表情
3. **動作序列** — CoreS3 記錄動作 → 播放 → StackChan 重現
